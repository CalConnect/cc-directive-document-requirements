== Abstract

This document provides requirements on the document structure of the following types of CalConnect publication: Directive, Standard, Guide, Specification, Amendment, Technical Corrigendum, and Report. It does not apply to policy statements, internal administrative documents, or how-to guides, although the processes described can optionally be used as guidance for those.
